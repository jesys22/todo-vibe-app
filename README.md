# To-Do List (Список задач) | Vibe Coder App

Простое, быстрое и адаптивное веб-приложение для управления задачами, созданное с использованием AI-инструментов (вайбкодинг).

## 🚀 Живая версия (Demo)
Вы можете посмотреть, как работает приложение, по ссылке:
👉 **[ВСТАВЬ ССЫЛКУ НА СВОЙ GITHUB PAGES]**

## ✨ Функционал
*   ✅ Добавление новых задач (по кнопке или клавише Enter).
*   ✅ Отметка выполненных задач (с визуальным зачеркиванием).
*   ✅ Удаление задач (с плавной анимацией).
*   ✅ Сохранение задач в `localStorage` (данные не пропадают при обновлении страницы).

## 🎁 Дополнительные фичи (сверх ТЗ)
*   🌙 Переключение на темную тему (сохраняется в браузере).
*   📊 Счетчик выполненных задач.
*   🗑️ Кнопка массовой очистки выполненных задач.
*   🛡️ Защита от XSS-уязвимостей (безопасный рендеринг текста).
*   📱 Адаптивный дизайн для мобильных устройств.

## 🛠️ Технологии
*   HTML5
*   CSS3 (без фреймворков, чистый CSS с переменными)
*   Vanilla JavaScript

## 🤖 Использованные AI-инструменты и подход
При создании проекта использовался подход **вайбкодинга**:
*   **Cline (Claude 3.5 Sonnet)** — основной ассистент для генерации структуры и логики.
*   **Cursor** — для навигации по файлу и мелких правок.
*   **ChatGPT** — для проверки безопасности.

**Мой процесс работы:**
1.  Написал четкий промпт с бизнес-требованиями.
2.  Проверил сгенерированный код. **Вручную исправил уязвимость**, заменив `innerHTML` на `textContent` для защиты от XSS.
3.  Провел тестирование (проверка на пустой ввод, сохранение после перезагрузки, ввод вредоносного скрипта).
4.  Задеплоил проект.

## 💻 Как запустить локально
Просто откройте файл `index.html` в любом современном браузере. Никакие серверы или установка зависимостей не требуются.
